# 栖课试听管理小程序

面向普通培训机构的微信小程序原型，包含课程与时段展示、试听预约、后台确认、到店签到、试听记录、评价展示和员工角色管理。

## 已实现的流程

1. 工作台展示今日预约、待确认和到店数据。
2. 前台新建试听预约，数据写入云数据库 `appointments`。
3. 前台将预约依次更新为“已确认”、“已到店”和“已完成”。
4. 试听完成时可填写试听记录（当前为前端交互；正式上线建议保存至 `trial_records` 集合）。
5. 管理页展示课程/可约时段、客户评价、员工启停与角色权限。

## 云开发部署

1. 用微信开发者工具导入本目录。
2. 在 `miniprogram/app.js` 填入自己的云开发环境 ID。
3. 右键 `cloudfunctions/quickstartFunctions`，选择“上传并部署：云端安装依赖”。
4. 在云开发控制台数据库创建 `appointments` 集合，权限选择“仅云函数读写”。
5. 编译小程序后，从“预约试听”新增记录，云端会开始持久化数据。

## 演示时手动切换角色

当前原型提供了演示角色切换，不需要登录：进入“管理”页面，在顶部“演示当前角色”下拉框中选择管理员、前台、老师或家长。选择后会保存到当前微信开发者工具的本地缓存，返回“工作台”即可看到当前角色标识。再次打开管理页仍会保持上次选择。

推荐演示顺序：

1. 选择“家长”，进入“预约”新建一条试听预约。
2. 选择“前台”，在预约列表点击“确认预约”和“到店签到”。
3. 选择“老师”，在已到店预约上点击“填写试听记录”。
4. 选择“管理员”，查看课程时间、客户评价和人员权限。

这是演示开关，不是正式权限控制。正式上线时应改为微信登录后由云函数根据 OpenID 返回角色，不能让用户自行选择管理员身份。

`appointments` 文档包含：学员姓名、年龄、联系电话、课程、日期时间、接待老师、预约状态、创建人 OpenID 和创建/更新时间。

## 正式上线前建议

课程、时间段、员工和评价页面现为机构默认演示数据。生产版应分别创建 `courses`、`schedules`、`staff`、`reviews`、`trial_records` 集合，并在云函数中按员工 `openid` 校验角色：

| 角色 | 允许操作 |
| --- | --- |
| 管理员 | 全部数据、课程、时段和人员管理 |
| 前台 | 新建/确认预约、到店签到 |
| 老师 | 查看本人课表、填写试听记录 |
| 家长 | 提交预约、提交一次课后评价 |

不要把数据库写权限开放给客户端；所有写入应通过云函数处理。
